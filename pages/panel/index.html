状态栏配置

            

            

              
              

                

                  

                    

                      
启用状态栏

                      
受大模型稀疏注意力机制影响，稳定性有限，切换后不保证每次生效。

                    

                    

                      
                    

                  

                  

                    
                    
                  

                  

                    
                    
                    留空则不显示该行。
                  

                  

                    
                    
                    字段未匹配到值时显示的文本，例如「未知」「—」。
                  

                  

                    

                      
标注字段变化

                      
可量化的字段（如好感度）相对上一轮的变化会带标注，形如「好感度：84/100（↑2）」。文本字段（心情、位置、当前想法）不加标注——它们每轮都在变，新值本身即信息，挂箭头只会淹没真正有价值的数值变化。

                    

                    

                      
                    

                  

                  

                    

                      
LLM 智能提取

                      
当状态栏格式完全不合规、5 级解析全部失败时，额外调用一次轻量 LLM 提取字段（3 秒超时）。开启后每次失败都会多消耗一次 LLM 调用。

                    

                    

                      
                    

                  

                  

                    
                    
                    留空则回退到 RAG 摘要 LLM。建议选择轻量、便宜的模型。
                  

                

                

                  

                    
                    
                    可用占位符 {content} 代表渲染后的状态栏正文。用于会渲染 Markdown 的平台（Discord、WebChat、飞书等）。
                  

                  

                    
                    
                    QQ、微信这类不渲染 Markdown 的平台用这份。默认模板里的 ** 与 ``` 在这些平台会原样显示给用户，故改用分隔线排版。
                  

                  

                    
                    
                    AstrBot 适配器名，用 | 分隔。留空默认包含 aiocqhttp、qq_official、wecom、dingtalk 等；未知平台一律走 Markdown 模板。
                  

                

              

            

          


          
          

            

              
决策模式（剧情走向推荐选择度）

            

            

              

                

                  
启用决策模式

                  
剧情选项附带「▸ 62%」倾向百分比；自由文字回复自动路由到最接近的分支。判定失败或置信度不足时保持普通渲染，不影响聊天。

                  
 决策模型没有对话接口，不能走 AstrBot 提供商，须在下方单独配置。开启即知悉：对话文本将发送至所配置的决策服务。

                

                

                  
                

              

              

                
                
                推荐 OpenRouter（默认已填）。也支持 TypeSafe / OpenAI / Hal-X / 云知声直连，可直接填完整端点。
              

              

                
                
                对应服务的 API Key。Hal-X 免鉴权可留空。
              

              

                
                

                  
                  
                

                如 inception/mercury-decide:free、typesafe/jev-1.14、openai/gpt-6-luna-decisions。「测试连接」按上面填写的地址、密钥与本处模型真发一次判定请求，不必先保存。
                

              

              

                
                
                自动即可；仅 OpenAI Decisions 格式的第三方网关需手动指定。
              

              

                
                
                置信度低于该值不显示百分比、不路由。0–1，默认 0.6。

在回复末尾显示注入报告

                    
每轮回复末尾附一行本轮命中构成（世界书/记忆/素材/文档及文档来源），用于核对灵敏度、top_k 等参数的调整效果。会进入聊天记录，纯沉浸 RP 时可关闭；关闭后仍可用 /quill debug 查看上一轮构成。

                  

                  

                    
                  

                

                

                  

                    
启用注入追踪

                    
记录每轮对话的注入诊断（命中了什么、注入顺序、各环节耗时），供 /quill debug 与面板「注入诊断」页排查「设定漏注入 / 角色失忆」类问题。纯内存记录，不写盘、不进对话，只读取注入流程已有数据，不产生额外模型调用。关闭后零采集零记录。

                  

                  

                    
                  

                

                

                  
                  
                  每个会话在内存中保留的最近追踪轮数（全局上限 200 轮，超限自动淘汰最旧）。重启后清空。
